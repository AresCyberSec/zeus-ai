# Zeus Source Code

This directory contains the core source code for Zeus.

## Structure

The source code is separated from configuration, persistent data, documentation, and development artifacts.

```text
src/
└── Core Zeus implementation
```

## Design Goal

As Zeus develops, functionality will be separated into independent components where practical.

Planned areas include:

* AI inference
* Conversation management
* Memory management
* Configuration
* Tool management
* Permission handling
* Security monitoring
* Logging

The architecture will evolve as new functionality is implemented.
